使用说明

MD → Word：导入或粘贴 Markdown，点击「导出 Word」。宽表格可以选择 A4 横向。

Word → MD：导入 .docx，自动提取 Markdown。可以继续编辑、复制或下载；如含图片，下载 ZIP 后解压，保持 Markdown 与 images 文件夹的相对位置。

Word 表格以首行为表头，单元格换行转为 <br>；合并单元格展开为普通网格并提示。字体、分页、页眉页脚等版式不保留。

旧版 .doc 或加密文档，请先用 Word / LibreOffice 另存为未加密的 .docx。扫描件不进行 OCR；Word 公式、SmartArt、图表等复杂对象可能无法提取，请留意转换提示。

MD → Word 的本地图片请通过「添加本地图片」选择 PNG、JPG、GIF 或 BMP 文件。远程图片不会联网下载。

Markdown 公式、Mermaid 和 HTML 等扩展语法不做专门渲染。内容仅保留在页面内存中，关闭页面后不会保存；两个转换方向的草稿可分别保留到本次页面关闭。
